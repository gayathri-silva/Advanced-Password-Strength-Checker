# Advanced Password Strength Checker

## Overview

The Advanced Password Strength Checker is a cybersecurity-focused project developed using Python and HTML/CSS/JavaScript. The tool evaluates password security by analyzing password length, character diversity, entropy, and common password usage.

It helps users create stronger passwords and understand security weaknesses that may expose their accounts to attacks such as brute-force and dictionary attacks.

---

## Features

### Python Version

* Password strength analysis
* Entropy calculation
* Detection of common weak passwords
* Uppercase, lowercase, number, and special character checks
* Security recommendations
* Color-coded strength results (Weak, Medium, Strong)

### Web Version

* Real-time password checking
* Interactive strength meter
* Password visibility toggle
* Password generator
* Copy password feature
* Password history using Local Storage
* Dark/Light mode
* Responsive modern user interface

## Password Evaluation Criteria

The system evaluates passwords using:

1. Password Length
2. Uppercase Characters
3. Lowercase Characters
4. Numbers
5. Special Characters
6. Password Entropy
7. Common Password Blacklist
